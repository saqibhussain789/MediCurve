# MediCurve

**MediCurve** is a full-stack health tracking application built using the MERN stack. It allows users to monitor their daily health vitals, visualize progress through interactive charts, and manage personal health records.

## Features
- User authentication (JWT)
- Vitals logging (BP, Sugar, etc.)
- Health progress charts
- Responsive dashboard
- Future-ready for doctor feedback and reminders

## Tech Stack
- React.js (Vite)
- Node.js + Express.js
- MongoDB
- Chart.js / Recharts
